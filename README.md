# ☕ Java Virtual Machine Programming

## 🚀 Overview

This repository focuses on understanding how Java works at a deeper level through the **Java Virtual Machine (JVM)**. It covers core concepts of system-level programming, memory management, execution flow, and internal working of Java programs.

The goal of this project is to build a strong foundation in **Java internals**, which is essential for backend development, system programming, and technical interviews.

---

## 🎯 Objectives

* Understand how Java code is executed inside JVM
* Learn about memory management and garbage collection
* Explore class loading and bytecode execution
* Strengthen core Java and system-level concepts

---

## 🧠 Topics Covered

* JVM Architecture
* Class Loader Subsystem
* Runtime Data Areas (Heap, Stack, Method Area)
* Execution Engine
* Garbage Collection
* JIT Compiler
* Bytecode & .class files
* Java Memory Model
